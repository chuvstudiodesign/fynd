# Color & Typography System

Use this skill when selecting, auditing, or documenting color and type for a brand across interfaces, marketing, and production files.

## Color architecture

Build a role-based palette: raw primitives plus semantic canvas, surface, text, border, action, status, and data roles. Add modes only when a light/dark or contextual system is genuinely needed. Give every accent a job; reserve the most energetic color for priority, action, or signal. Use tokens and aliases so a correction propagates cleanly.

## Typography architecture

Choose type based on voice, clarity, language support, licensing, numerals, and product performance. Define display, headline, body, UI, and data roles, then document family, weight, size, line height, tracking, case behavior, and exclusions. Body copy must stay calm and scannable.

## Accessibility

For normal text target at least 4.5:1 contrast; for large text, at least 3:1. Do not rely on color alone to communicate status or state. Check the actual foreground/background pair, including patterned and gradient contexts. Return approved pairs, type styles, and token guidance ready for Figma or code.
